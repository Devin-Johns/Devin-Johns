### Hi, I'm Devin 👋

IT Operations Engineer at Grafana Labs, working on identity and access
management (Okta), SaaS administration, and internal tooling that AI
agents can drive.

**Okapi** is the project I'd point at first: an AI-powered Okta
administration CLI I built in Python, wrapping 51 tools across user
lifecycle, MFA and factor resets, groups and dynamic group rules, app
assignments, admin roles, audit log search, and bulk reporting. Destructive
operations run behind an explicit confirmation model, credentials come from
1Password rather than a config file, and it ships as a double-clickable
macOS app for teammates who don't live in a terminal.

Most of the activity above is in private company repositories. Alongside
Okapi, it's mostly:

- **Identity and access.** Okta SSO and SAML integrations, group and
  lifecycle management, and the access runbooks our IT team routes
  tickets against.
- **Docs as code.** Our internal runbook library in Markdown, reviewed
  through pull requests and validated in CI. Recent work covers SSO,
  Claude Enterprise administration, and security incident response.
- **Agent-native knowledge.** Skills and conventions that let coding
